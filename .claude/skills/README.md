# Скіли проєкту

Скіли з плагіна Finance від Anthropic
(https://github.com/anthropics/knowledge-work-plugins/tree/main/finance), ліцензія Apache 2.0 — див. `LICENSE-finance-skills`.

- `reconciliation` — звірки (банк, контрагенти, залишки)
- `close-management` — закриття місяця
- `financial-statements` — P&L, баланс, рух коштів
- `variance-analysis` — план-факт і причини відхилень
- `journal-entry`, `journal-entry-prep` — бухгалтерські проводки
- `audit-support`, `sox-testing` — аудит (переважно американські стандарти)
